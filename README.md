# חומרה ל-Brik — מחקר רכש

מדריך רכש של חומרה יצירתית (בסגנון Teenage Engineering / M5Stack / Adafruit) לחיבור לפלטפורמת **Brik** — כלים שרצים ב-iframe מבודד. כל רכיב מלווה באופן החיבור ל-Brik, מחיר מאומת מול דף המוצר, ורעיון לדמו.

**האתר החי:** https://elirazdekalowix.github.io/brik-hardware-research/

## שתי גרסאות

- **[organized.html](organized.html)** — ✨ הגרסה המאורגנת: 244 רכיבים ב-10 קטגוריות פונקציונליות, תמונה לכל רכיב, הסבר והפניות רכש בראש כל קטגוריה.
- **[index.html](index.html)** — מסמך המחקר הרציף המקורי (קטלוג מלא + תרחישי תקציב $5,000 / $1,000).

בשתי הגרסאות: **רשימת קניות אינטראקטיבית** (סימון רכיבים, שמירה בדפדפן, סכום משוער, חלקים נלווים להפעלה) ו**מחולל רעיונות** (רעיון מהמחקר + 2 חדשים לכל רכיב + רעיונות מיקס יצירתיים בין הרכיבים).
